# Документация проекта «ОРБИТА»

Эта папка — учебник по проекту. Он написан так, чтобы его мог прочитать человек, который
только начинает работать с анимациями: каждое понятие объясняется с нуля, у каждого решения
есть «почему», а у каждого эффекта — инструкция, как перенести его в другой проект (в том
числе на React, Vue, Next.js или вообще без сборщика).

## Где ещё документация

- **README в каждой папке модуля** (`src/modules/*/README.md`) — подробно про конкретный эффект:
  как работает, почему так, какие у него настройки, как перенести.
- **Комментарии в коде.** Каждый файл начинается с блока «что это и зачем», а неочевидные
  строки прокомментированы прямо на месте. Комментарии отвечают на вопрос «почему», а не
  пересказывают код.
- **Тесты** (`*.test.js` рядом с кодом) — живые примеры того, как вызывать функции и что
  они возвращают.

## Как читать код, если вы новичок

1. Откройте `index.html` — это вся вёрстка страницы. Найдите атрибуты `data-module="…"`:
   каждый такой атрибут «включает» модуль с этим именем.
2. Откройте `src/main.js` — здесь видно, как имя модуля превращается в код.
3. Выберите один модуль, например `src/modules/sliders/ring/`. Прочитайте его `README.md`,
   потом `math.js` (чистая логика, без браузера), потом `index.js` (подключение к странице).
4. Запустите `npm run dev`, откройте страницу и меняйте числа в коде — Vite сразу
   перезагрузит страницу. Лучший способ понять анимацию — сломать её и посмотреть, что
   изменилось.
