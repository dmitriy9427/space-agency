# Разбор кода: модуль за модулем

[Понятия](../02-concepts.md) объясняют **идеи** (твин, таймлайн, ScrollTrigger, пружины), README в
папках модулей — **что** делает эффект и как его перенести. Здесь — **код**: ключевые модули
разобраны порциями, после каждой — что она делает и почему так.

Каждая страница: где на экране → что делает → разметка → код по частям → что будет, если убрать
строку → вопросы с ответами.

| # | Страница | Модуль | Чему научит |
| --- | --- | --- | --- |
| 1 | [Первый экран](01-hero.md) | `hero` | SplitText с маской, таймлайн интро, `gsap.context` и `revert` |
| 2 | [Манифест](02-manifesto.md) | `manifesto` | слова по прокрутке, счётчики через объект-посредник, ScrambleText |
| 3 | [История миссии](03-story.md) | `story` | `pin` + `scrub`, сцены на одном таймлайне, шина событий, CSS-переменная неба |
| 4 | [Фильтр снимков](04-flip-filter.md) | `flip-filter` | Flip: First-Last-Invert-Play, страница не прыгает |
| 5 | [Полёт ракеты](05-rocket-flight.md) | `rocket/flight.js` | путевые точки, интерполяция по прокрутке, чистые функции |

Если слова «твин», «таймлайн», «scrub» пока незнакомы — сначала [02. Понятия](../02-concepts.md)
и [словарь](../glossary.md).
