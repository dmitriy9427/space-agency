# 1. Первый экран

[src/modules/hero/index.js](../../src/modules/hero/index.js)

## Где на экране

Главная, первый экран: заголовок «ВЫШЕ ШУМА» собирается по буквам — каждая выезжает снизу из
«щели» с лёгким поворотом, волной слева направо. Надпись над ним «расшифровывается» из случайных
букв. Потом проявляются подзаголовок и кнопки. При прокрутке весь блок уезжает вверх медленнее
страницы и гаснет, а подсказка «прокрутите» покачивается.

## Разметка

```html
<section data-module="hero">
  <div class="hero__inner" data-hero-parallax>
    <p class="eyebrow" data-hero-eyebrow>Основано в 2026 · низкая околоземная орбита</p>
    <h1 class="hero__title" data-hero-title>Выше<br />шума</h1>
    <p class="hero__lead" data-hero-fade>…подзаголовок…</p>
    <div class="hero__actions" data-hero-fade>…кнопки…</div>
  </div>
  <p class="hero__hint" data-hero-hint>Прокрутите, чтобы взлететь ↓</p>
</section>
```

## Код по частям

### Всё внутри `gsap.context`

```js
export function init(el, ctx) {
  const d = createDisposer()
  const g = gsap.context(() => {
    if (ctx.reduced) return
    …все анимации…
  }, el)
  d.add(() => g.revert())
  return { destroy: () => d.dispose() }
}
```

`gsap.context(функция, область)` — «запиши всё, что создано внутри». Потом `g.revert()` одним
вызовом:

- убивает все твины и ScrollTrigger этого модуля;
- **откатывает** нарезку SplitText — в заголовке снова просто текст, а не сотня `<div>`;
- снимает inline-стили, поставленные анимациями.

Второй аргумент `el` — **область селекторов**: `'[data-hero-hint]'` ищется только внутри секции, а
не по всей странице.

`if (ctx.reduced) return` — при «уменьшить движение» не создаётся ничего: страница как есть.

### Буквы из щели

```js
const split = title && SplitText.create(title, { type: 'chars, words', mask: 'chars', charsClass: 'hero__char' })
```

- `type: 'chars, words'` — режем на буквы **и** слова. Слова нужны, чтобы браузер не переносил
  строку посреди слова: каждая буква — отдельный элемент, и без обёртки-слова перенос мог бы
  случиться между любыми буквами.
- `mask: 'chars'` — каждая буква оборачивается в контейнер с `overflow: clip`. Буква, сдвинутая
  вниз на 115%, полностью спрятана — «под полом».

```js
const intro = gsap.timeline({ defaults: { ease: 'expo.out' }, delay: 0.2 })
intro.from(split.chars, {
  yPercent: 115,
  rotate: 12,
  duration: 1.4,
  stagger: { each: 0.035, from: 'start' },
})
```

- `from` — «из этого состояния в текущее»: буквы начинают на 115% ниже и повёрнутыми, приходят на
  место.
- `yPercent` — сдвиг в процентах **от высоты самой буквы**: работает при любом размере шрифта.
- `stagger.each: 0.035` — каждая следующая буква на 35 мс позже: волна.
- `expo.out` — очень быстрое начало и долгое мягкое торможение: буквы «выстреливают».

```js
intro.from(eyebrow, { duration: 1.4, scrambleText: { text: eyebrow.textContent, chars: 'upperCase', speed: 0.6 } }, 0)
intro.from(fades, { y: 30, autoAlpha: 0, duration: 1, stagger: 0.1 }, 0.6)
```

Третий аргумент — **позиция на таймлайне**: `0` — одновременно с буквами, `0.6` — через 0,6 с от
начала. Без него каждый шаг ждал бы конца предыдущего.

### Параллакс при прокрутке

```js
gsap.to('[data-hero-parallax]', {
  yPercent: -35,
  autoAlpha: 0.15,
  ease: 'none',
  scrollTrigger: { trigger: el, start: 'top top', end: 'bottom top', scrub: true },
})
```

- От «верх секции у верха экрана» до «низ секции у верха экрана» блок уезжает вверх на 35% своей
  высоты — медленнее, чем едет страница. Это и есть параллакс.
- `scrub: true` — прогресс анимации = прогресс прокрутки: крутите назад — блок возвращается.
- `ease: 'none'` — со `scrub` почти всегда: скорость задаёт сама прокрутка.

```js
gsap.to('[data-hero-hint]', { y: 8, repeat: -1, yoyo: true, duration: 1.1, ease: 'sine.inOut' })
```

`repeat: -1` — бесконечно, `yoyo` — туда-обратно. `sine.inOut` — мягкое покачивание без рывков в
крайних точках.

## Что будет, если…

| Убрать | Что сломается |
| --- | --- |
| `gsap.context` + `revert` | после перехода на другую страницу и обратно заголовок нарезан дважды |
| `type: 'words'` | перенос строки посреди слова |
| `mask: 'chars'` | буквы видны внизу, пока «выезжают» |
| позицию `0` у eyebrow | расшифровка начнётся только после всех букв |

## Проверьте себя

1. Почему `yPercent`, а не `y: 100`?
2. Как сделать, чтобы буквы шли волной справа налево?

<details>
<summary>Ответы</summary>

1. `yPercent` — от высоты буквы: прячется ровно под маску при любом размере шрифта; `100px` при
   крупном шрифте не спрятали бы букву полностью.
2. `stagger: { each: 0.035, from: 'end' }`.
</details>
