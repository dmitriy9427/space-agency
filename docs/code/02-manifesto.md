# 2. Манифест

[src/modules/manifesto/index.js](../../src/modules/manifesto/index.js), [format.js](../../src/modules/manifesto/format.js)

## Где на экране

Главная, после первого экрана: крупный абзац сначала почти прозрачный, и пока вы прокручиваете,
слова по очереди «загораются» — читаешь в темпе прокрутки. Ниже цифры «384+», «7.8 км/с», «1 204»
отсчитываются от нуля, а подписи над ними расшифровываются из символов `0 1 < > / #`.

## Разметка

```html
<p data-reveal-words>Мы летаем не ради рекордов…</p>
<dl>
  <dt data-scramble>Запусков</dt>
  <dd data-count="384" data-suffix="+">0</dd>
  <dt data-scramble>Скорость</dt>
  <dd data-count="7.8" data-suffix=" км/с">0</dd>
</dl>
```

## Код по частям

### Слова загораются по прокрутке

```js
const split = SplitText.create(text, { type: 'words' })
gsap.fromTo(split.words, { opacity: 0.12 }, {
  opacity: 1,
  ease: 'none',
  stagger: 0.1,
  scrollTrigger: { trigger: text, start: 'top 78%', end: 'bottom 50%', scrub: true },
})
```

**Stagger внутри scrub.** Обычно stagger — «каждый следующий на 0,1 с позже». Со `scrub` времени
нет — есть путь прокрутки. GSAP раскладывает слова по этому пути: каждое загорается на своём
отрезке. Остановили прокрутку на середине абзаца — горит ровно половина слов.

Начальная прозрачность 0,12, а не 0: абзац виден заранее, человек понимает, что тут текст, и
начинает читать.

### Счётчики: анимировать объект-посредник

```js
const state = { value: 0 }
const write = () => (counter.textContent = formatCount(state.value, options))

ScrollTrigger.create({
  trigger: counter,
  start: 'top 85%',
  once: true,
  onEnter: () => gsap.to(state, { value: target, duration: 2.2, ease: 'power3.out', onUpdate: write }),
})
```

Анимировать **текст** нельзя: у GSAP нет «свойства» «число в тексте». Зато GSAP анимирует **любое
числовое свойство любого объекта**. Поэтому:

1. заводим обычный объект `{ value: 0 }`;
2. GSAP плавно меняет `state.value` от 0 до 384;
3. `onUpdate` на каждом кадре пишет текущее значение в текст.

Этот приём пригодится везде, где значение нельзя анимировать напрямую: проценты в кольце, цена,
положение камеры.

`once: true` — сработать один раз и удалить триггер: цифры не пересчитываются при прокрутке назад.

```js
// format.js
export const decimalsOf = (raw) => (String(raw).split('.')[1] ?? '').length
```

Знаков после запятой — столько же, сколько в атрибуте: `"7.8"` → один знак, и анимация идёт
`0.0 → 7.8`, а не `0 → 8`. `formatCount` ставит тонкий пробел (U+2009) между разрядами — «1 204», как принято в русской
типографике, — и настоящий минус «−» вместо дефиса.

### Подписи расшифровываются

```js
gsap.from(label, {
  duration: 1.2,
  scrambleText: { text: label.textContent, chars: '01<>/#', revealDelay: 0.2 },
  scrollTrigger: { trigger: label, start: 'top 85%', once: true },
})
```

ScrambleText показывает случайные символы из набора и постепенно открывает настоящие.
`revealDelay` — первые 0,2 с только «шум».

### При «уменьшить движение»

Слова сразу горят, счётчики сразу показывают итог (`state.value = target; write()`), подписи не
шифруются.

## Что будет, если…

| Сделать | Что сломается |
| --- | --- |
| `opacity: 0` у слов | абзац выглядит пустым местом, пока до него не докрутили |
| без `once: true` у счётчика | цифры начинают заново при каждом возвращении к блоку |
| `ease: 'power2.out'` со `scrub` у слов | слова в начале загораются медленнее прокрутки, в конце — быстрее |
| без `decimalsOf` | «7.8 км/с» отсчитывается целыми: 0, 1, 2… 8 |

## Проверьте себя

1. Почему нельзя написать `gsap.to(counter, { textContent: 384 })`?
2. Что произойдёт, если остановить прокрутку на середине абзаца и подождать?

<details>
<summary>Ответы</summary>

1. Можно (у GSAP есть свой разбор чисел в `textContent`), но формат — разряды, знаки после запятой,
   суффикс — уже не под вашим контролем. Объект-посредник даёт полный контроль над текстом.
2. Ничего: со `scrub` анимация стоит вместе с прокруткой — горит та часть слов, до которой
   докрутили.
</details>
