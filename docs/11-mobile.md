# 11. Мобильная версия: что и где сделано

Сайт делался сначала для компьютера, места для телефона были помечены в коде `МОБИЛКА:`.
Теперь они доработаны. **Правила CSS для телефона собраны в одном файле —
`src/styles/mobile.css`** (подключается последним). Логика — в модулях, ниже по списку.

## 1. Навигация

| Где | Что сделано |
| --- | --- |
| `modules/nav` + `base.css` (до 860px) | бургер в шапке; меню на весь экран раскрывается кругом из точки бургера, пункты влетают по очереди (один GSAP-таймлайн, закрытие — он же назад) |
| там же | пока меню открыто: страница не прокручивается, Tab ходит по меню, Esc закрывает; ссылка или смена страницы — закрывает |
| HTML | временная плашка «пока для компьютера» удалена |

## 2. Высота экрана

Закреплённые секции (`100vh`) получили `100svh` — высоту без учёта выезжающей адресной строки
(`100vh` строкой выше остался запасным для старых браузеров).

## 3. Жесты: вертикальный свайп — прокрутка страницы

| Модуль | Решение |
| --- | --- |
| Стопка (`sliders/stack`) | палец тянет карточку только вбок (`type: 'x'`), у колоды `touch-action: pan-y` |
| Шейдерный слайдер (`sliders/shader`) | на тач-экране листание только горизонтальным свайпом, `pan-y` |
| Вода (`liquid`) | без рисования пальцем: волны от тапа и «дождя» |
| Галерея (`gallery`) | без наклона карточек на тач-экране |

## 4. Наведение — на телефоне его нет

Подсказки «Наведите…», «Проведите курсором…», «Колесо…» — парами: `.for-mouse` и `.for-touch`,
показывается подходящая к устройству (`@media (pointer: coarse)`). Видеолента раскрывается по
тапу; курсор на тач-экранах выключен.

## 5. Размеры и раскладка (`mobile.css`)

- Заголовки секций меньше (широкий шрифт заглавными не влезал и обрезался).
- **`min-width: 0`** у блоков флота: дорожка видеоленты (`max-content`) растягивала колонку шире
  экрана — края слайдеров и подписей обрезались. Типичная ловушка CSS Grid.
- Кольцо — карточки 52vw; ленты, барабан, видеолента (карточка 180px) — под телефон.
- Миссии: карточка ленты 78vw. Направления: мини-схема скрыта, заголовок меньше, счётчик —
  наверх (внизу наезжал на цифры).

## 6. Ракета

`rocket/flight.js`: для портрета — своя таблица `WAYPOINTS_PORTRAIT` (`waypointsFor(aspect)`):
на старте ракета стоит на площадке внизу справа, взлетает по «коридору» у правого края (текст
манифеста на телефоне уже — 72%), садится внизу. Поворот экрана → `ScrollTrigger.refresh` →
таблица выбирается заново.

## Как тестировать

1. DevTools → Toggle device toolbar (Ctrl/Cmd + Shift + M) → iPhone/Android, **перезагрузить**
   страницу (часть проверок — один раз при загрузке).
2. На реальном телефоне: `npm run dev -- --host` → откройте `http://<ip-компьютера>:5173`.
   Эмуляция не показывает настоящую производительность и поведение адресной строки.
