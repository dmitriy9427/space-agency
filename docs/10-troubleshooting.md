# 10. Частые проблемы и решения

## Анимации

| Симптом | Причина | Решение |
| --- | --- | --- |
| Свойство вроде `scrollTrigger`, `drawSVG`, `morphSVG` ничего не делает, ошибок нет | Плагин не зарегистрирован | Импортировать GSAP из `src/core/gsap.js` |
| ScrollTrigger срабатывает не в том месте | Высота страницы изменилась после расчёта (шрифты, картинки, новый контент) | `ScrollTrigger.refresh()`; включить `markers: true` и посмотреть линии |
| Пины «сползают», секции налезают друг на друга | Пины созданы не по порядку | `ScrollTrigger.sort()` после создания (сделано в `app.js`) или `refreshPriority` |
| `position: fixed` элемент едет вместе со страницей | Он внутри ScrollSmoother (у родителя transform) | Вынести из `#smooth-content` |
| После твина элемент «застрял» маленьким/сдвинутым | Твин с `overwrite: true` убил другой твин (например, `quickTo`) | `overwrite: 'auto'` (история в `cursor/README.md`) |
| GSAP «запёк» CSS `scale`/`translate` и не даёт их менять | GSAP читает отдельные свойства `scale`/`translate`/`rotate` в свою матрицу | Анимировать через GSAP или разнести на разные элементы (пример — `.cursor__ring` / `.cursor__bubble`) |
| Текст после SplitText ломается посреди слова | Резали только на `chars` | `type: 'words, chars'` |
| SplitText нарезал криво | Резали до загрузки шрифта | `document.fonts.ready.then(…)` или `autoSplit: true` |
| Анимация на 120 Гц быстрее, чем на 60 | Формула без учёта времени кадра | `damp(...)` или умножать на `dt` (docs/02-concepts.md, 2.2) |
| Цепочка пружин «взрывается» | Недодемпфированные звенья усиливают друг друга | Передемпфированные звенья (`cursor/rope.js`) |

## Прокрутка и раскладка

| Симптом | Причина | Решение |
| --- | --- | --- |
| Страница прыгает при фильтре/раскрытии | Элемент на время анимации вынут из потока или страница стала короче | Зафиксировать высоту контейнера на время анимации (`flip-filter`) |
| Дыры в бесконечной сетке | Число ячеек не делится на число колонок | `data-count` кратно колонкам (`gallery/README.md`) |
| Колесо «застревает» в слайдере | Перехват вертикального колеса | Перехватывать только горизонтальное (`deltaX > deltaY`) |
| На телефоне нельзя прокрутить страницу над эффектом | `touch-action: none` | `touch-action: pan-y` (docs/11-mobile.md) |

## WebGL

| Симптом | Причина | Решение |
| --- | --- | --- |
| Текстура чёрная | Картинка не загрузилась к моменту создания текстуры | `await loadImage(src)` перед `new Texture(img)` (+ `needsUpdate = true`) |
| Ошибка «cross-origin» / «tainted» | Картинка с чужого домена без CORS | Положить картинку к себе |
| Картинка в WebGL темнее, чем в `<img>` | Не указано цветовое пространство | `texture.colorSpace = SRGBColorSpace` и `#include <colorspace_fragment>` в шейдере |
| Объект с шейдером пропадает у краёв | three отсекает по исходной геометрии | `mesh.frustumCulled = false` |
| После нескольких переходов «WebGL context lost» | Контексты не освобождаются | `releaseRenderer` в `destroy()` сцены |
| Шейдер не компилируется: `half` | В GLSL ES `half` — зарезервированное слово | Переименовать переменную |

## Видео

| Симптом | Причина | Решение |
| --- | --- | --- |
| `play()` падает с NotAllowedError | Браузер запретил автозапуск со звуком | `muted` + `playsinline`; ошибку ловить (`playVideo` в `core/media.js`) |
| Ролик начинается с титров | — | Отрезок `start`/`end` в `content/videos.js` |

## Переходы между страницами

| Симптом | Причина | Решение |
| --- | --- | --- |
| После перехода эффект не работает | Обработчики висели на старых элементах | Делегирование событий на `document` (как в `cursor`) или перезапуск модуля (модули страниц перезапускаются сами) |
| После перехода что-то задвоилось | Модуль старой страницы не убрал за собой | Проверить `destroy()` (`createDisposer`) |
| Новая страница не попала в сборку | Не добавлена в `vite.config.js` | `rollupOptions.input` |

## Отладка

- **`?debug`** — FPS, `window.__orbita` (контекст, текущая страница, `navigate(url)`).
- **`markers: true`** в любом ScrollTrigger — линии start/end на странице.
- **`gsap.globalTimeline.timeScale(0.2)`** в консоли — замедлить все анимации в 5 раз, чтобы
  рассмотреть переход.
- **DevTools → Rendering → Paint flashing** — что перерисовывается.
