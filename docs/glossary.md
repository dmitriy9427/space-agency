# Словарь терминов

| Термин | Что значит |
| --- | --- |
| **Кадр (frame)** | Одно обновление экрана; 60 или 120 раз в секунду. |
| **FPS** | Кадров в секунду. 60+ — плавно. |
| **rAF, requestAnimationFrame** | «Вызови функцию перед следующим кадром» — основа любой анимации в браузере. |
| **Тикер (ticker)** | Цикл кадров GSAP; на него подписываются все наши анимации. |
| **dt, delta time** | Время с прошлого кадра. Нужно, чтобы скорость не зависела от FPS. |
| **Твин (tween)** | Анимация свойств от одного значения к другому за время. |
| **Таймлайн (timeline)** | Контейнер твинов с расписанием. |
| **Ease, кривая сглаживания** | Как меняется скорость анимации во времени (равномерно, с разгоном, с отскоком). |
| **Stagger** | Сдвиг старта для группы элементов: «волна». |
| **Scrub** | Прогресс анимации привязан к прокрутке. |
| **Pin, закрепление** | Секция стоит на месте, пока прокрутка проигрывает анимацию. |
| **Параллакс** | Слои движутся с разной скоростью — ощущение глубины. |
| **containerAnimation** | ScrollTrigger внутри горизонтальной анимации (лента миссий). |
| **Flip** | Приём First-Last-Invert-Play: анимировать «перестановку» элементов в DOM. |
| **Прокси (proxy)** | Невидимый элемент, который тянет Draggable, а мы переводим его координату во что-то другое (угол кольца). |
| **Инерция** | Движение продолжается после отпускания и затухает. |
| **Snap, доводка** | После броска остановиться на «правильном» месте (на карточке). |
| **Пружина (spring)** | Значение тянется к цели с силой ∝ расстоянию; трение гасит скорость. |
| **Демпфирование** | Трение пружины. Передемпфированная — без перелёта, недодемпфированная — с колебаниями. |
| **Заворот (wrap)** | Число «по кругу»: ушло за конец — появилось с начала. Основа бесконечных лент. |
| **Lerp** | Линейная интерполяция: точка между a и b. |
| **Damp** | Плавное догоняние цели, не зависящее от FPS. |
| **Делегирование событий** | Один обработчик на родителе вместо обработчиков на каждом элементе. |
| **Шина событий (bus)** | Модули общаются через имена событий, не зная друг о друге. |
| **Модуль** | В проекте — папка с функцией `init(el, ctx) → { destroy }`. |
| **Контекст (ctx)** | Общие данные для всех модулей: шина, качество, reduced motion, скролл. |
| **Утечка** | Обработчики/анимации/контексты, не убранные после удаления эффекта. |
| **Layout / Paint / Composite** | Этапы отрисовки браузера; `transform` и `opacity` обходят дорогой Layout. |
| **WebGL** | Рисование на видеокарте из браузера. |
| **three.js** | Библиотека для WebGL: сцена, камера, объекты, материалы. |
| **Mesh** | 3D-объект: геометрия (форма) + материал (вид). |
| **Шейдер** | Программа на видеокарте (язык GLSL). Вершинный — где точки, фрагментный — какого цвета пиксели. |
| **Uniform** | Значение, передаваемое из JS в шейдер (время, прогресс). |
| **Varying** | Значение, передаваемое из вершинного шейдера во фрагментный. |
| **UV** | Координаты текстуры 0…1. |
| **Текстура** | Картинка на видеокарте. |
| **CORS** | Правило безопасности: WebGL не может брать картинки с чужого сайта без разрешения. |
| **fbm, шум** | «Природная» случайность для рваных краёв, облаков, огня. |
| **Пинг-понг** | Две текстуры, которые меняются ролями «читаю/пишу» каждый шаг симуляции. |
| **Additive blending** | Цвета складываются как свет — для огня, искр, неона. |
| **Draw call** | Одно обращение к видеокарте «нарисуй это». Меньше — быстрее. |
| **DPR, плотность пикселей** | Сколько физических пикселей в одном CSS-пикселе (Retina — 2–3). |
| **Reduced motion** | Системная настройка «уменьшить движение». |
| **touch-action** | CSS: какие жесты пальцем браузер отдаёт странице (прокрутка), а какие — нам. |
| **HMR** | Горячая перезагрузка Vite: изменения видны без перезагрузки страницы. |
| **Progressive enhancement** | Сначала всё работает без JS, анимации — «надстройка». |
