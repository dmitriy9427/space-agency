# sliders/video-strip — видеолента (слайдер №5)

Ряд узких карточек-роликов шире экрана. Наводите на карточку, и она раскрывается в 3 раза. Лента сама подъезжает, чтобы раскрытая карточка оказалась по центру, и запускается ролик NASA. Курсор ушёл с ленты: карточка сворачивается, ролик встаёт на паузу. Ленту можно тянуть мышью с инерцией. Сделано по образцу VideoSlider из UguKit.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `layout.js` | Чистая геометрия: `expandedWidth` (ширина раскрытой), `trackBounds` (границы перетаскивания), `focusX` (сдвиг дорожки для центровки), `isInView`. Тесты: `layout.test.js`. |
| `index.js` | Подключение: Draggable дорожки, наведение с задержкой, синхронные твины ширины, видео. Тесты: `index.test.js`. |

## Разметка

```html
<div class="vstrip" data-module="video-strip">
  <div class="vstrip__track" data-vstrip-track>
    <article class="vstrip__card" data-vstrip-card tabindex="0">
      <img class="vstrip__poster" src="poster.jpg" alt="">
      <video class="vstrip__video" muted loop playsinline preload="none"
             data-src="ролик.mp4" data-start="0" data-end="15"></video>
      <span class="vstrip__label">Подпись свёрнутой</span>
      <span class="vstrip__content">
        <span data-vstrip-content>…</span>   <!-- выезжает при раскрытии -->
      </span>
    </article>
    …
  </div>
</div>
```

В проекте карточки генерирует шаблон `videos` (`src/content/render.js`) по данным из `src/content/videos.js`.

## Настройки

| Что | Где | По умолчанию |
| --- | --- | --- |
| Ширина обычной карточки | CSS `--vstrip-card-width` (`src/styles/sliders.css`) | 260px |
| Во сколько раз шире раскрытая | `EXPAND_RATIO` в `layout.js` | 3 |
| Длительность и кривая раскрытия | `DURATION`, `EASE` в `index.js` | 0.8 с, `power3.inOut` |
| Задержка наведения / сворачивания | `HOVER_DELAY`, `LEAVE_DELAY` | 250 / 200 мс |
| Ролики, постеры, отрезки | `src/content/videos.js` (`start`, `end`) | — |

## Как работает

1. **Раскрытие** — три твина с одинаковыми длительностью и кривой, запущенные одновременно: новая карточка расширяется, старая сужается, дорожка едет (`x` из `focusX`). Поэтому движение выглядит одним целым. Ширину анимирует GSAP (а не CSS transition), чтобы раскрытие можно было прервать на полпути без рывка.
2. **Границы Draggable** пересчитываются на каждом кадре раскрытия (`onUpdate: updateBounds`), потому что длина дорожки меняется.
3. **Три защиты от «нервного» поведения:**
   - задержка наведения;
   - «заморозка» наведения на время анимации: под неподвижный курсор подъезжает соседняя карточка, и она не должна раскрыться цепочкой;
   - наведение считается по `pointermove`, а не по `pointerenter`.
4. **Видео.**
   - Атрибут `src` ставится только при первом раскрытии (`preload="none"` + `data-src`), до этого ролик не грузится.
   - Крутится только отрезок `[start, end)` (`loopSegment` в `core/media.js`).
   - Видео проявляется поверх постера, только когда реально заиграло (класс `is-playing`).
5. **Клик** (Draggable вызывает `onClick` только если не тянули). По раскрытой карточке — пауза или продолжение, по свёрнутой — раскрытие.
6. **Клавиатура.** Tab по карточкам раскрывает их, Enter или пробел ставят на паузу и продолжают.

## Перенос

Нужны `index.js`, `layout.js`, `core/media.js`, `core/lifecycle.js`, стили `.vstrip*`. GSAP: Draggable + InertiaPlugin. В React: `useEffect(() => { const s = init(ref.current, ctx); return () => s.destroy() }, [])` (подробно — `docs/06-porting.md`).

## Мобилка

На тач-экранах наведения нет: раскрытие работает по тапу (ветка «МОБИЛКА» в `onClick`). Для мобильной версии уменьшить `--vstrip-card-width` (около 180px) и проверить высоту карточек.

## Подводные камни

- Ролики стримятся с серверов NASA. Если сервер недоступен, карточка останется с постером (ошибка `play()` ловится).
- Автозапуск видео браузеры разрешают только без звука, поэтому у видео стоит `muted`.
