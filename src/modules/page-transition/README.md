# page-transition — переход между страницами («занавес»)

При переходе на другую страницу снизу поднимается тёмный «занавес» с рваной светящейся кромкой (оранжевый → голубой) и закрывает экран. Под ним страница подменяется. Затем занавес продолжает движение вверх и открывает новую страницу. Он проходит насквозь, без отката назад, поэтому переход выглядит одним непрерывным движением.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `curtain.js` | Чистая логика: шкала прогресса 0…2 и две границы занавеса (`curtainEdges`), прозрачность для запасного варианта. Тесты: `curtain.test.js`. |
| `transition.glsl.js` | Шейдер: всё между двумя границами закрашено, граница «рваная» за счёт fbm-шума, светящийся кант, звёзды. |
| `transition.scene.js` | three.js: прозрачный canvas на весь экран. Рисуется только во время перехода. |
| `index.js` | `createTransition(ctx)` → `play(swap)`: закрыть, вызвать `swap()`, дождаться, открыть. |

## Использование

```js
const transition = await createTransition(ctx)

await transition.play(async () => {
  // экран закрыт: здесь подменяем страницу (может быть асинхронно)
})
```

Модуль не знает про роутер, `swap` может делать что угодно. Переход использует `src/app.js` (функция `navigate`).

## Настройки

`COVER_DURATION` / `REVEAL_DURATION` и кривые — в `index.js`. Цвета канта и тела занавеса — `uColorA`, `uColorB`, `uBase` в `transition.scene.js`. «Рваность» края — число `0.22` в `transition.glsl.js`, частота шума — `p * 3.0`.

## Без WebGL и при reduced motion

Вместо шейдера тёмный слой с плавной прозрачностью (класс `.page-transition--fallback`).

## Перенос на React/Next/Vue

`play(() => router.push(url))` — и дождаться монтирования новой страницы (вернуть промис из swap). Подробно — `docs/06-porting.md`.
