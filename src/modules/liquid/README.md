# liquid — водная гладь

Фото туманности «лежит под водой». Курсор оставляет рябь, клик бросает камень, а в простое на поверхность падает дождь.

| Файл | Что делает |
| --- | --- |
| `ripple.js` | Чистая логика: `pointerToUv`, сила капли от скорости `strengthFromSpeed`, капли вдоль пути `dropsAlongPath`, дождь `createRain`, очередь `createDropQueue` (не больше `MAX_DROPS` за шаг). |
| `ripple.glsl.js` | Симуляция «высота + скорость»: точка тянется к среднему соседей, скорость затухает (`uDamping`). Отображение: нормаль из градиента преломляет фото с дисперсией каналов и бликом на гребнях. |
| `ripple.scene.js` | Две half-float текстуры состояния (ping-pong), шаг симуляции, вывод. Без float-текстур возвращает `null`, и остаётся обычное фото. |
| `index.js` | События мыши, дождь после `RAIN_DELAY` секунд простоя, цикл только пока секция на экране. |

## Производительность

- Симуляция в низком разрешении (160–288 px по меньшей стороне, `quality.tier`). Это 2 полноэкранных прохода по маленькой текстуре и 1 вывод на кадр.
- Вне экрана цикл стоит.
- Без WebGL или без float-текстур показывается обычное `<img>`.

## Перенос в другой проект

- **Файлы:** `index.js`, `ripple.js`, `ripple.scene.js`, `ripple.glsl.js` + `core/env.js`, `core/media.js`, `core/webgl.js`; стили `.liquid*`.
- **GSAP:** только тикер GSAP + three.js.
- Фото должно быть с вашего домена (CORS) — docs/02-concepts.md, раздел 2.10.

Общий порядок переноса и примеры для React/Vue/Next — `docs/06-porting.md`.
