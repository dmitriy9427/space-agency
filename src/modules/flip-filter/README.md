# flip-filter — фильтр сетки с анимацией Flip

Кнопки «Все / Планеты / Туманности / …» и сетка снимков. Нажали кнопку: лишние снимки уменьшаются и тают, оставшиеся плавно переезжают на новые места, сетка становится ниже. Используется на странице «Миссии».

## Разметка

```html
<section data-module="flip-filter">
  <button data-filter="all" aria-pressed="true">Все</button>
  <button data-filter="Планеты" aria-pressed="false">Планеты</button>
  <div class="fgrid__grid">
    <figure data-flip-item data-category="Планеты">…</figure>
  </div>
</section>
```

Категории карточек ставит шаблон `filter-grid`. Список категорий — `CATEGORIES` в `src/content/photos.js` (название кнопки → какие значения `kind` фото в неё входят).

## Как работает (First → Last → Invert → Play)

```js
const state = Flip.getState(items)                       // First: запомнить, где все
items.forEach((item) => item.classList.toggle('is-hidden', …)) // Last: мгновенно скрыть/показать
Flip.from(state, { absolute: true, onEnter, onLeave })    // Invert + Play
```

- **`absolute: true`** — на время анимации карточки вынимаются из сетки, исчезающие не мешают раскладке.
- **`onEnter` / `onLeave`** — анимации для появившихся и исчезающих.
- **После анимации** вызывается `ScrollTrigger.refresh()`: высота сетки изменилась, позиции всего ниже сдвинулись.

## Почему страница не прыгает

Без защиты при каждом клике по табу страница «скакала». Причин две:

1. **Сетка схлопывается во время анимации.** `absolute: true` вынимает все карточки из потока, и сетка схлопывается до нуля. Поэтому высота сетки фиксируется на старте и плавно анимируется к новой.
2. **Страница становится короче уже прокрученного.** Если сетка уменьшилась, а вы были близко к концу страницы, браузер «подтягивает» прокрутку. Поэтому сетке остаётся `min-height` (`keepRoomFor`), и страница не становится короче.

В конце, если табы всё же сдвинулись, прокрутка подкручивается так, чтобы табы остались на месте.

## Добавить категорию

Добавьте ключ в `CATEGORIES` (`src/content/photos.js`) и кнопку `<button data-filter="Ключ">` в HTML.

## Перенос в другой проект

- **Файлы:** `index.js` + разметка с `data-filter` / `data-flip-item`; стили `.chip`, `.fgrid*` из `pages.css`.
- **GSAP:** Flip, ScrollTrigger (только для `refresh()` — можно убрать, если на странице нет ScrollTrigger).
- В React удобнее хранить фильтр в состоянии, но анимацию всё равно делайте через `Flip.getState` до изменения DOM и `Flip.from` после (в `useLayoutEffect`).

Общий порядок переноса и примеры для React/Vue/Next — `docs/06-porting.md`.
