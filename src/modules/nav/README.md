# nav — шапка сайта

Общий слой: живёт на всех страницах.

1. **Якоря на текущей странице** (`/#fleet`, когда вы на главной) — плавная прокрутка к секции: через `smoother.scrollTo`, а если ScrollSmoother выключен, через ScrollToPlugin. Ссылки на **другие** страницы шапка не трогает, их перехватывает роутер (`src/core/router.js`) и показывает переход-занавес.
2. **Прячется при прокрутке вниз** и возвращается при прокрутке вверх (`shouldShowHeader`).
3. **Полоса прогресса** прокрутки страницы (`[data-nav-progress]`).
4. **Пункт текущей страницы** получает `aria-current="page"` (подсветка в `pages.css`, этот же атрибут читают скринридеры). Обновляется по событию шины `page:change`.

## Добавить пункт меню

Допишите `<a href="/новая.html">…</a>` в `.nav__links` **во всех HTML-файлах** (шапка общая, но в каждом файле своя копия). Подсветка и переход заработают сами.

## Мобилка

На экранах уже 860px меню просто прячется (`base.css`). Нужна кнопка-«бургер» и выезжающее меню (`docs/11-mobile.md`).

## Перенос в другой проект

- **Файлы:** `index.js` + `core/router.js` (функции `isSamePage`, `normalizePath`); стили `.nav*` из `base.css`.
- **GSAP:** ScrollTrigger, ScrollToPlugin (и ScrollSmoother, если он есть).
- В React/Next навигация обычно своя (Link) — оставьте из модуля только «прятать при прокрутке» и полосу прогресса.

Общий порядок переноса и примеры для React/Vue/Next — `docs/06-porting.md`.
