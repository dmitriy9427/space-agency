# page-intro — интро страницы по строкам

Заголовок появляется **по строкам**: каждая строка выезжает снизу из-под «маски» со сдвигом по времени. Надпись над заголовком «расшифровывается», остальное проявляется. Используется на странице «Миссии».

```html
<header data-module="page-intro">
  <p data-intro-eyebrow>// миссии</p>
  <h1 data-intro-lines>Длинный заголовок в несколько строк</h1>
  <p data-intro-fade>Подзаголовок</p>
</header>
```

**Как работает.** `SplitText.create(title, { type: 'lines', mask: 'lines', autoSplit: true, onSplit })`. Текст режется на строки **так, как их перенёс браузер**. `mask` прячет строку под «полом», `autoSplit` режет заново при изменении ширины окна (строки переносятся иначе), а `onSplit` возвращает анимацию, и SplitText корректно её заменяет.

**Перенос.** Один файл, нужен только SplitText и ScrambleText. Работает на любом заголовке.

## Перенос в другой проект

- **Файлы:** `index.js`.
- **GSAP:** SplitText, ScrambleText.
- С `autoSplit: true` возвращайте анимацию из `onSplit` — так SplitText корректно перезапустит её при ресайзе.

Общий порядок переноса и примеры для React/Vue/Next — `docs/06-porting.md`.
