# gallery — бесконечный архив снимков

Сетка фото без краёв. Её можно тянуть в любую сторону, крутить горизонтальным колесом, листать стрелками. Пока секция закреплена, прокрутка страницы тоже двигает сетку. В покое сетка медленно дрейфует. Колонки едут с разной скоростью, на быстром движении карточки сжимаются и наклоняются. Клик по фото раскрывает его на весь экран с подписью (лайтбокс на Flip). Устройство взято из InfiniteGallery (UguKit), код написан заново.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `grid.js` | Чистая математика: `wrapCell` (заворот), `columnSpeed`, `squeezeScale`, `velocityUnit`, `centerOn`. Тесты: `grid.test.js`. |
| `index.js` | Цель и текущее положение, жесты (Observer), колесо, стрелки, пин от ScrollTrigger, дрейф, лайтбокс. |
| `lightbox.js` | Раскрытие фото на весь экран через Flip. Работает с любой картинкой и не зависит от галереи. Тесты: `lightbox.test.js`. |

## Разметка

```html
<section data-module="gallery">
  <div data-gallery-pin>
    <div data-gallery-viewport tabindex="0">
      <div data-gallery-grid>
        <figure data-gallery-item><div class="gallery__card"><img data-photo="p01" …></div></figure>
        …
      </div>
    </div>
  </div>
</section>
```

В проекте ячейки генерирует шаблон `gallery`: `<div data-gallery-grid data-render="gallery" data-photos="all" data-count="40">`.

## ⚠️ Главное правило: никаких дыр

**Число ячеек должно делиться на число колонок.** Иначе последний ряд неполный, и при завороте сетки по вертикали пустые места ряда видны как дыры.

- Колонок: CSS `--gallery-columns` (8, а на узком экране 5).
- Ячеек: `data-count="40"` в `index.html`. 30 фото повторяются по кругу до 40, то есть 8 × 5 и 5 × 8.
- Сетка должна быть больше окна хотя бы на одну ячейку по каждой оси (`--gallery-grid-width: 170vw`).

Если правило нарушено, модуль пишет предупреждение в консоль.

## Настройки

`OPTIONS` в `index.js`:

| Параметр | Что делает | По умолчанию |
| --- | --- | --- |
| `lag` | Инерция: за сколько секунд сетка проходит ~63% пути до цели | 0.22 |
| `dragSpeed` | px сетки на 1 px движения руки | 2 |
| `columnStep` | Разница скоростей соседних колонок | 0.08 |
| `scrollFollow` | px сетки на 1 px прокрутки страницы | 1.1 |
| `drift` | Дрейф в покое, px/с `[x, y]` | `[-18, -10]` |
| `tilt` | Наклон карточек на скорости, градусы | 10 |
| `pinLength` | Сколько прокрутки секция закреплена | `'+=120%'` |

CSS: `--gallery-columns`, `--gallery-grid-width`, `--gallery-gap` в `src/styles/effects.css`.

## Как работает

1. Два положения: **цель** `(tx, ty)` и **текущее** `(cx, cy)`. Все источники ввода (рука, колесо, прокрутка, дрейф, стрелки) меняют только цель. Каждый кадр текущее положение догоняет цель экспоненциально (не зависит от FPS).
2. Каждую ячейку сдвигаем `transform`-ом на текущее положение и «заворачиваем» по модулю размера сетки (`wrapCell`).
3. Отставание текущего от цели примерно равно скорости. Отсюда сжатие и наклон.
4. Сетка догнала цель и не дрейфует — кадр не рисуется вовсе.
5. Клик открывает лайтбокс (а после перетаскивания клик гасится). Пока лайтбокс открыт, сетка замирает, а плавный скролл стоит на паузе.

## Перенос

`index.js` + `grid.js` (+ `lightbox.js`), стили `.gallery*` и `.lightbox*`. Требует GSAP Observer, ScrollTrigger и Flip. Пин можно убрать (удалить блок `ScrollTrigger.create`), тогда это обычный блок в потоке страницы.

## Мобилка

Сетка тянется пальцем, но вертикальный свайп отдаётся странице (`touch-action: pan-y`). Размеры для телефона — черновые (медиазапрос в `effects.css`).
