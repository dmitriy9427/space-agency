# cursor — неоновая «тянучка», подсказки, магнитные кнопки

Общий слой: живёт на всех страницах и не пересоздаётся при переходах.

- **Хвост.** За курсором тянется светящаяся линия от белого к голубому, фиолетовому и оранжевому, на резких движениях сыплется звёздная пыль.
- **Подсказка.** Над элементом с атрибутом `data-cursor="тяни"` появляется белый круг с текстом.
- **Магнитные кнопки.** Элементы с `data-magnetic` (или `data-magnetic="0.5"` — сила) смещаются к курсору и упруго возвращаются.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `rope.js` | Физика хвоста: цепочка передемпфированных звеньев, фиксированный шаг 60 Гц. В шапке файла разобрано, почему первая версия «взрывалась». Тесты: `rope.test.js`. |
| `magnetic.js` | `magneticOffset`: насколько кнопка тянется к курсору. |
| `index.js` | Canvas хвоста (3 прохода свечения в режиме `lighter`), пыль, подсказка, магнит. |

## Разметка

```html
<div class="cursor" data-module="cursor" aria-hidden="true">
  <canvas class="cursor__trail"></canvas>
  <span class="cursor__ring"><span class="cursor__bubble"><span class="cursor__label"></span></span></span>
</div>
```

`.cursor__ring` только едет за курсором (его `transform` пишет GSAP), а **масштабируется вложенный `.cursor__bubble`**. Если масштабировать сам ring CSS-свойством `scale`, GSAP «запечёт» стартовый масштаб в свою матрицу, и подсказка навсегда останется маленькой. На этом проект однажды споткнулся.

## Делегирование событий

Обработчики висят на `document`, а не на каждой кнопке. В момент события ищется `event.target.closest('[data-magnetic]')`. Поэтому магнит и подсказки работают и на элементах, которые появились позже, например на страницах, загруженных роутером.

## История бага с магнитом

Первая версия: `quickTo` для следования и `gsap.to(..., { overwrite: true })` для возврата. `overwrite: true` убивает **все** твины свойства, включая внутренний твин `quickTo`, и после первого наведения магнит переставал работать. Сейчас: на каждое движение короткий `gsap.to` с `overwrite: 'auto'`, который заменяет только предыдущий твин того же элемента. Регрессионный тест: «магнит работает и при повторном наведении».

## Настройки

`POINTS` (длина хвоста), `HEAD_WIDTH` (толщина), `COLORS`, `MAX_DUST` — в `index.js`. Жёсткость и инерция хвоста — параметры `createRope` (`pull`, `inertia`, `follow`). Размер подсказки — `.cursor__bubble` в `effects.css`.

## Мобилка

На тач-экранах курсора нет: модуль удаляет свою разметку, и ничего менять не нужно.

## Перенос в другой проект

- **Файлы:** `index.js`, `rope.js`, `magnetic.js` + `core/env.js`, `core/lifecycle.js`; стили `.cursor*` и `.has-cursor` из `effects.css`; разметка `.cursor` в `<body>` (вне ScrollSmoother).
- **GSAP:** ядро GSAP (`quickTo`, `ticker`).
- Модуль живёт всё время, пока открыт сайт. В React монтируйте его один раз в корневом layout, а не на каждой странице.

Общий порядок переноса и примеры для React/Vue/Next — `docs/06-porting.md`.
